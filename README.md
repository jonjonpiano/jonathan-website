# Meine erste Website – Jonathan

Willkommen! Das ist deine persönliche Website, gebaut mit **HTML** und **CSS**.

## So öffnest du die Website

1. Öffne den Ordner `/Users/jonathan/dev/jonathan-website` im Finder
2. Doppelklicke auf `index.html`
3. Die Seite öffnet sich in deinem Browser

Alternativ: Rechtsklick auf `index.html` → „Öffnen mit" → Chrome, Safari oder Firefox

## Dateien

| Datei        | Was sie macht                          |
|--------------|----------------------------------------|
| `index.html` | Der Inhalt der Seite (Text, Struktur)  |
| `style.css`  | Das Design (Farben, Schrift, Layout)   |

## Was du anpassen kannst

- **Deine Interessen** – ändere die Texte in den Karten unter „Meine Interessen"
- **E-Mail** – ersetze `jonathan@beispiel.de` mit deiner echten Adresse
- **Farben** – in `style.css` oben bei `:root` findest du die Farben (z.B. `--accent`)

## Nächste Schritte

- Füge ein echtes Foto von dir hinzu
- Lerne **JavaScript** für interaktive Elemente
- Veröffentliche die Seite kostenlos auf [GitHub Pages](https://pages.github.com) oder [Netlify](https://netlify.com)
